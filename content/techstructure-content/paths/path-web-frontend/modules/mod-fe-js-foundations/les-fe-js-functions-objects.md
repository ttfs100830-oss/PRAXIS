# JavaScript Functions, Arrays, and Objects

**Lesson ID:** `les-fe-js-functions-objects`  
**Classification:** Core  
**Module:** JavaScript Fundamentals

## Learning goal

Manipulate JS objects and iterate over arrays.

## Core concept

Functions package reusable behavior; parameters receive inputs and return values communicate results. Objects group properties and methods, and references mean two variables can refer to the same object. Arrow functions differ from regular functions in how they bind this and in other language details. Prefer clear functions with narrow responsibilities and explicit inputs.

## Worked example / guided practice

Create a function that accepts an array of prices and returns the total. Test an empty array and a typical array, then explain whether the function mutates its input.

## Common mistake to avoid

Avoid relying on implicit globals or confusing object identity with equal-looking object contents.
