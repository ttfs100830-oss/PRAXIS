# CSS Box Model, Flexbox, and Responsive Design

**Lesson ID:** `les-fe-css-layout-responsive`  
**Classification:** Core  
**Module:** HTML, CSS & Browser Rendering

## Learning goal

Build adaptable layouts using CSS Flexbox and media queries.

## Core concept

CSS controls presentation and layout. The box model includes content, padding, border, and margin; box-sizing changes how declared dimensions are calculated. Flexbox is useful for one-dimensional alignment, Grid for two-dimensional layouts, and media queries adapt styles to viewport conditions. Responsive design should preserve readability and functionality across widths.

## Worked example / guided practice

Create a card row using flex or grid, then adapt it to a single column on a narrow viewport. Test overflow and ensure controls remain usable without horizontal scrolling.

## Common mistake to avoid

Avoid fixed widths that assume one screen size; test the actual layout at multiple viewport widths.
