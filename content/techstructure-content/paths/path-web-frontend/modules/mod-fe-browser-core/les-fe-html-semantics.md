# Semantic HTML Document Structure and Forms

**Lesson ID:** `les-fe-html-semantics`  
**Classification:** Core  
**Module:** HTML, CSS & Browser Rendering

## Learning goal

Structure web documents using semantic HTML elements.

## Core concept

HTML describes document structure. Semantic elements communicate purpose: headings establish hierarchy, nav groups navigation, main marks primary content, button performs an action, and a anchors navigate to a URL. Correct labels and heading order help assistive technologies and make pages easier to maintain. Use div/span only when no more meaningful element fits.

## Worked example / guided practice

Build a small page with header, nav, main, one h1, a section heading, a labeled form field, a button, and a link. Explain why the button and link are not interchangeable.

## Common mistake to avoid

Use a button for actions and an anchor for navigation; styling does not change an element’s semantics.
