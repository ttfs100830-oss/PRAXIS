# Open-Source Packages and Software Licenses

**Lesson ID:** `les-dev-oss-licensing`  
**Classification:** Core  
**Module:** Runtimes & Package Management

## Learning goal

Evaluate third-party packages for license compatibility.

## Core concept

Open-source software is distributed under a license that grants specific permissions and imposes conditions. Permissive licenses and copyleft licenses differ in obligations; neither category means “no rules.” Check the actual license text, attribution requirements, notices, patent clauses, and project policies before redistributing software.

## Worked example / guided practice

For a dependency in a sample project, locate its license file and record the license name and any notice/attribution requirement. Escalate unclear commercial or redistribution cases rather than guessing.

## Common mistake to avoid

This lesson is educational, not legal advice. License obligations depend on the license, how software is used, and jurisdiction.
