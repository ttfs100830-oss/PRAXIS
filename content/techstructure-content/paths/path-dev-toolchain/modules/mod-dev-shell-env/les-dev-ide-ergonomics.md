# Code Editors, Language Servers, and Debuggers

**Lesson ID:** `les-dev-ide-ergonomics`  
**Classification:** Core  
**Module:** Shells, Environment & Editor Mastery

## Learning goal

Configure an IDE with interactive breakpoint debugging.

## Core concept

An IDE/editor combines editing, navigation, diagnostics, debugging, and extensions. Useful habits include formatting consistently, searching symbols rather than scrolling, using integrated terminal output, inspecting diffs, and learning a few high-value shortcuts. Extensions can help but also add latency, permissions, and conflicting behavior.

## Worked example / guided practice

Choose one shortcut each for symbol search, file search, formatting, and opening the terminal. Use them on a small project, then disable an extension only if you can identify a reproducible conflict.

## Common mistake to avoid

Editor automation should make behavior repeatable; do not treat a green diagnostic badge as proof that software is correct.
