# Solutions — CPU, RAM, and Persistent Storage

**Lesson ID:** `les-comp-cpu-memory`  
**Scope:** Explain how instructions and data flow from persistent disk into volatile RAM and are executed.

## Worked answers and grading notes

### Solution 1
Explain that the program file is stored persistently, the OS loads required code/data into RAM, and the CPU executes instructions using registers and caches as applicable.

### Solution 2
Power loss normally clears volatile RAM; a file saved successfully to persistent storage normally remains.

### Solution 3
A valid diagram labels storage → loading/runtime → RAM/cache/registers/CPU, then shows output being written back to storage.
