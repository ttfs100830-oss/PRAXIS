# Caching Strategies with Redis — Solution Guide

**Lesson ID:** `les-dist-caching-redis`

This guide gives the expected reasoning and a grading rubric. For open-ended tasks, equivalent correct implementations are acceptable; learners should use the tools and language chosen for their project.

## Exercise 1 — Explain

**Expected answer:** Reduce database load using Redis in-memory caching.

A complete response should name the central components or concepts, explain how they relate, and avoid claiming guarantees that the mechanism does not provide.

## Exercise 2 — Apply

A valid solution should document:

1. **Starting state and preconditions** — enough detail for another person to reproduce the setup.
2. **Operation** — the exact action taken, including relevant input or configuration.
3. **Expected result** — a specific output, state transition, or observable behavior.
4. **Verification** — a test, command output, log entry, or inspection that confirms the result.
5. **Failure case** — one invalid input or unavailable dependency and the expected way it is surfaced.

There is no single universal code answer because the manifest scope does not mandate a particular programming language or framework.

## Exercise 3 — Troubleshoot

Good answers identify several distinct causes rather than repeating the same guess. Examples of useful categories include invalid input, incorrect configuration, missing permission or dependency, a mismatch between expected and actual state, and a failure in a preceding step. The learner should select evidence that distinguishes these causes before changing the implementation.

## Mastery task rubric

| Criterion | Points | Full-credit evidence |
|---|---:|---|

**Mastery threshold:** 8/10, with no critical correctness issue.

## Assessment answer guidance

- **Q1:** Restate the lesson scope accurately and explain the central mechanism.
- **Q2:** Give a concrete starting state, operation, expected result, and verification method.
- **Q3:** Identify a plausible failure mode and the evidence that would reveal it.
- **Q4:** Provide a relevant, testable example aligned with the lesson scope.
- **Q5:** Ask for reproducible steps, expected versus actual results, and evidence.

Open-ended answers should be assessed for correctness and reasoning, not exact wording.
