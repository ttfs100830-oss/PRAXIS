# Solutions and grading guide: Network Troubleshooting CLI Tools (curl, ping, dig)

**Lesson ID:** `les-net-troubleshooting-cli`

## Assessment answer key

1. **A.** Network troubleshooting works best layer by layer: resolve the name, test reachability where appropriate, verify the port/service, inspect HTTP response and TLS, then check application logs.
2. **B.** Inspect the current state, define expected behavior, and change one thing at a time.
3. **C.** A failed ping does not prove a website is down; ICMP may be blocked.
4. **Short answer rubric (2 points):** 1 point for an accurate explanation of the mechanism; 1 point for connecting it to the stated learning goal. Accept equivalent technically correct explanations.
5. **Practical rubric (3 points):** 1 point for relevant steps or an artifact; 1 point for stating expected and actual behavior; 1 point for explaining a realistic limitation or failure mode.

## Practice / mastery task guidance

A complete submission should demonstrate the goal: **Diagnose network failures using command-line diagnostic tools.**. Use this process:

1. State the starting condition and expected behavior.
2. Perform a small, reproducible task related to the concept.
3. Capture the output, screenshot description, command, code, or diagram that supports the result.
4. Explain why the result occurred and identify one limitation.

**Review note:** The practical task allows multiple valid implementations. Grade reasoning and evidence rather than requiring one exact tool or operating system.
